# Move Canvas — Working-Name Research

**Checked:** 2026-11-19  
**Scope:** Working-name screening, not legal or trademark clearance.

## Result

`Move Canvas` is acceptable as the working name when paired with the descriptor
**create and play motion games**. An exact web search found generic “move
canvas” interface language but no active same-name/same-service product.
GitHub repository search returned unrelated canvas-movement code examples, and
`npm view move-canvas` returned `E404`.

Formal trademark, app-store, and domain clearance remain necessary before a
commercial launch. No domain or mark was purchased or reserved.

## Naming rules

- Public display name: **Move Canvas**
- Repository/package slug: `move-canvas`
- Never publish `MoveCanvas` as the primary user-facing name.
- Descriptor: **Turn an idea into a motion game you can play on a TV.**

# Implementation Handoff — Move Canvas

Build the frozen package in `project-package.md`. Treat stable requirement IDs
as the contract and route every variance through the factory verifier.

## Operating contract

1. Prove the hardest uncertainty first: two browser contexts pair and exchange
   low-latency semantic input; then replace test input with local pose events.
2. Build the smallest complete create → review → calibrate → pair → play → save
   path before secondary themes or presentation material.
3. AI returns data, never executable code. Validate against the frozen schema
   and movement allow-list before presentation or runtime use.
4. Raw camera frames stay in the controller process. Never persist or transmit
   frames, recordings, embeddings, or face identity.
5. The user reviews and approves the exact blueprint before play.
6. Provide a clearly labeled deterministic fallback; do not silently present
   fallback output as model output.
7. Test permission denial, body not framed, tracking loss, peer disconnect,
   invalid blueprint, model timeout, reload, keyboard use, reduced motion, and
   narrow mobile/TV layouts.
8. Do not claim fitness outcomes, users, adoption, novelty, revenue, or
   performance until independently measured.

## First implementation sequence

1. Scaffold Next.js/TypeScript and CI-quality commands.
2. Define `GameBlueprint`, semantic gesture, calibration, controller event,
   session, and result schemas with unit tests.
3. Implement deterministic blueprint fallback and game runtime.
4. Implement structured AI route and frozen evaluation corpus.
5. Build creator/editor and local demo controls.
6. Add MediaPipe camera calibration and gesture classifier.
7. Add signaling/WebRTC controller-display connection and recovery.
8. Run full verification and preserve evidence before publication work.

## Required completion output

Return a requirement-status table, exact verification commands/results,
architecture and privacy decisions, AI evaluation/provenance/cost evidence,
controller latency measurements, device/browser matrix, accessibility and
performance results, screenshots, known limitations, safe public claims, and
the exact next factory route.

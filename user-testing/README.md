# Move Canvas User Testing

This directory separates simulated persona inspection from real-participant
evidence. Package 1.3 is the first intake.

- `persona-matrix-1.3.md` freezes the initial coverage.
- `user-testing-plan-1.3.md` defines tasks and evidence boundaries.
- Session artifacts and the final report must be produced by the permanent
  **Portfolio Factory — User Testing Lab** room.

No real participant, interview, quotation, lived-experience, accessibility
conformance, or adoption claim exists until a consented session is retained.
